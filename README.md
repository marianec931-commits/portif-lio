# Portfólio Mariane Costa

Este é o meu portfólio pessoal, feito **apenas com HTML e Tailwind CSS**, sem JavaScript.  
O objetivo do site é apresentar quem eu sou, minhas habilidades, minha formação e meu contato.

## Sobre o site

- **Cabeçalho**: Contém meu nome e o menu de navegação com links para cada seção.
- **Seções**:  
  - Apresentação  
  - Sobre mim  
  - Habilidades  
  - Formação  
  - Contato  
- **Rodapé**: Contém meu nome e ano.
- **Tailwind CSS**: Todas as cores, alinhamentos e estilos foram aplicados usando classes prontas do Tailwind.  
- **Projetos**: A seção foi removida porque ainda não possuo projetos no momento.
